# 8051 Control Labs

计算机控制原理课程的 8051 汇编实验合集。

## 内容

- `p1/`：键盘输入、LED 显示、基础输出
- `p2/`：定时与计数
- `p3/`：中断、定时器、数码管、综合控制
- 根目录若干独立练习程序

主要示例：

- LED 循环显示
- 按键输入
- 定时器中断
- 数码管扫描
- 简单状态控制

## 工具

- 8051 汇编
- WAVE6000 / 伟福仿真器
- 汇编器与十六进制文件生成工具

## 运行

1. 使用 WAVE6000 或兼容的 8051 仿真环境打开 `.ASM`。
2. 根据实验指导书设置时钟、端口和外设。
3. 编译生成 `.BIN` / `.HEX` 后下载到实验平台。

仓库只保留源代码，不包含仿真器安装包、课程报告和编译产物。

## 说明

- 原始实验中的 `.DSK`、`.BIN`、`.HEX` 和报告未上传。
- 不同实验平台的端口映射可能不同，使用前需要按开发板原理图调整。
- 根目录和 `p1` 中保留了原实验的不同版本，便于对照修改。
